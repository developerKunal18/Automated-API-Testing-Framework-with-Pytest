🧠 Why Automated Testing?

Imagine your API has 50 endpoints.

After changing one function:

Developer Changes Code
        │
        ▼
   Run Test Suite
        │
   ┌────┴────┐
   ▼         ▼
 PASS       FAIL
   │         │
   ▼         ▼
Deploy    Fix Bug

Instead of manually checking every endpoint, Pytest can test everything in seconds.

The goal is:

Code → Test → Build → Deploy
         ❌
       Stop if
       tests fail
